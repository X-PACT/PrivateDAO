## Repository Implication

The current public homepage still exposes some historical specialist links
and legacy technology language. This repository README intentionally does not
repeat those claims as current product commitments. Public route cleanup is a
separate web release and must be tested against redirects, SEO metadata, and
rollback requirements.

## Availability Boundary

The presence of a live link proves that a route is published, not that every
underlying feature is production-certified. Product maturity must be read from
the corresponding source, runtime evidence, and deployment status.
