# Agent Exchange Distribution Pack

This folder contains public, machine-readable submission artifacts for lawful directory registration. It does not claim that a directory has listed PrivateDAO until a confirmed public listing URL is recorded.

- Agent Card: https://agents.privatedao.org/.well-known/agent-card.json
- MCP: https://agents.privatedao.org/mcp
- A2A: https://agents.privatedao.org/a2a
- OpenAPI: https://agents.privatedao.org/openapi.json
- Developer guide: https://agents.privatedao.org/connect
