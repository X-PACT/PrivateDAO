# Agent Acquisition Playbook

## The public funnel

1. Agent reads `/.well-known/agent-card.json`.
2. Agent calls free `verify.basic`.
3. Agent receives a deterministic result and receipt.
4. Agent requests a paid service only when deeper evidence is needed.
5. Agent signs its own Solana payment.
6. Agent receives a result and verifies the receipt.
7. Agent can register its own service and be discovered through logistics.

## Rules

- Contact maintainers and opt-in communities; do not mass-message bots.
- Never fabricate agents, usage, volume, rankings, or revenue.
- Sponsored placement stays explicitly labeled and never changes verification truth.
- Report real external agents separately from PrivateDAO services and test agents.
