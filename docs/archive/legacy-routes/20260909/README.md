# Archived Legacy Routes

These directories contain generated static snapshots that were removed from
the active source tree after confirming that the current application owns the
corresponding product routes:

- `tracks/encrypt-ika` -> `/services/encrypt-ika-operations/`
- `tracks/umbra-confidential-payout` -> `/services/umbra-confidential-payout/`

The old public paths retain minimal redirect stubs. The archived snapshots are
kept for recovery and provenance, but are not part of the active product
source or discovery surface.
