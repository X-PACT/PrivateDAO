# Dependency Security Review

Date: 2026-09-11

## Scope

The audit was run against the canonical repository lockfile with scripts
disabled. Production runtime dependencies and development dependencies are
reported separately because the two sets have different exposure and release
boundaries.

## Current result

Production-only audit (`npm audit --omit=dev`):

- Total: 21
- Critical: 0
- High: 2
- Moderate: 2
- Low: 17

Full dependency graph audit:

- Total: 36
- Critical: 0
- High: 14
- Moderate: 3
- Low: 19

## Remediation applied

The repository already contains a bounded-width local `bigint-buffer`
implementation. The npm override now forces transitive consumers to resolve
that local implementation instead of the vulnerable registry package. The
production-only high count decreased from 5 to 2, and the release verification
suite remains 9/9 passing.

## Deferred risks

The remaining production high findings are the `toml` advisory reached through
`@coral-xyz/anchor`. npm reports no non-forced fix for this dependency chain.
Anchor/TOML is not replaced blindly because it is coupled to Solana program
tooling and changing it without protocol regression evidence could break
builds or deployment workflows. Mainnet release remains gated on dependency
review and explicit human approval.

The remaining low/moderate findings are retained for targeted remediation.
`npm audit fix --force` is explicitly not accepted as a remediation method.

## Boundary

This record does not claim that all dependency risk is closed. It records the
current evidence, the safe remediation that was applied, and the exact risk
that remains deferred. No private keys, wallet files, environment files, or
runtime secrets are included.
