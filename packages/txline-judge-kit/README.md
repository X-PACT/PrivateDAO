# TxLINE Match Settlement — Evaluator Kit

1. Watch the [three-minute product demo](https://privatedao.org/videos/txline-settlement-demo-3min.mp4).
2. Run `npm test` to verify the public receipt contract and tamper failure.
3. Run `npm run demo` to view a deterministic sample receipt.
4. Review the hosted [API reference](https://privatedao.org/developers/txline-settlement-api/) and [product](https://privatedao.org/txline-settlement/).

This evaluator kit intentionally excludes private inputs, browser proving code, circuits, proving and verification artifacts, service credentials, wallet material, and deployment configuration.
